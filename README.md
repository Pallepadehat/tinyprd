# TinyPRD 🧠📄

**En lille sprogmodel, der former rodede produktidéer til gode PRD'er. Den skriver fra groft til fint, ligesom et menneske.**

> 🚧 Under opbygning. Den fulde README, dokumentation og resultater kommer snart.

TinyPRD er et skoleprojekt i machine learning. Det bygger på idéen bag
[Next-Concept Modeling (NCM)](https://hazyresearch.stanford.edu/blog/2026-10-12-ncm) fra Stanford Hazy Research.
